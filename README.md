# 博研合作方知识工作台

广东博研文化服务有限公司面向合作方的业务知识工作台，基于 Cherry Studio 开发，面向 Windows 和 macOS。

合作方可查询博研业务资料、制定城市落地方案、准备合作提案和筹备课程活动。模型服务由使用者自行配置，客户端可继续分发。

## 产品规划

| 能力 | 内容 |
|---|---|
| 业务知识库 | 科创教育、成人 AI 培训、AI 营地、AI 黑客松等业务资料 |
| 业务智能体 | 了解博研、城市落地规划、合作方案、课程与活动筹备 |
| 来源引用 | 回答关联本地原文，支持按章节核对资料 |
| 知识更新 | 飞书资料发布为版本化知识包，客户端自动更新 |
| 自选模型 | 使用个人 API Key 连接模型服务 |
| 桌面主题 | Apple 风格界面，支持浅色、深色和跟随系统 |
| 离线资料 | 本地浏览、全文检索和离线知识包导入 |

## 使用流程

1. 安装或解压客户端。
2. 配置模型服务商、API Key 和模型。
3. 选择业务智能体并输入问题。
4. 查看回答及来源，编辑或导出方案草稿。

资料浏览与本地全文检索无需模型 Key。模型问答需要连接所配置的服务商，检索片段随请求发送至该服务商。

## 资料更新

博研在飞书维护对外资料，发布器生成签名知识包，客户端校验后更新本地知识库。用户无需飞书账号。联网运行时自动检查更新，离线时保留最后成功版本。
